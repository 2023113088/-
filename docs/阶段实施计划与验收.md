# library-cloud — 实施说明（已实现 / 未实现）

仓库根目录：`library-cloud/`。

---

## 已实现

| 类别 | 内容 |
|------|------|
| 实验 PDF (1) | 多模块 Maven、`library-common`、Spring Boot 3.2 + Spring Cloud 2023 |
| 实验 PDF (2) | `borrow-service` → `BOOK-SERVICE`：OpenFeign、LoadBalancer、Resilience4j、`BookFeignFallbackFactory` |
| 实验 PDF (3) | Eureka；各服务 `spring.application.name` 注册 |
| 实验 PDF (4) | Gateway：`lb://` 路由、JWT、白名单 |
| PPT 拓扑 | Nginx（默认宿主机 `18888`）反代到 `gateway-service:18080` |
| 配置中心 | `config-server` + `config-repo`；镜像内本地 Git（`file:///git-config`）；各服务 `spring.config.import` 指向 Config（`optional`，本地未起 Config 时不强制失败） |
| 数据 | 默认 profile：H2；`docker` profile：MySQL 三库 userdb / bookdb / borrowdb |
| 安全与隔离 | 内部库存接口 `PUT /api/books/{id}/stock` 需 `X-Internal-Token`；Feign 自动带令牌与 `X-Trace-Id`；JWT 与 `INTERNAL_SERVICE_TOKEN` 分离 |
| 错误与校验 | RFC 7807 `ProblemDetail`、`@Valid`、网关 401 为 `application/problem+json` |
| Docker | Compose 项目名 `library-cloud`、网络 `library-cloud-backend`、MySQL 命名卷；`env.example` / `.env` 可配宿主机端口与密钥；默认 MySQL 映射 **13306** |
| 联调 | `docker compose up -d --scale book-service=2` 可验证 BOOK-SERVICE 多实例与负载均衡 |
| 其它 | 各服务 Actuator `health`；springdoc（直连各服务端口 Swagger） |

**本地 IDE 联调启动顺序**：`eureka-server` → 各业务服务 → `gateway-service`。网关默认宿主机 **18080**（`.env` 中 `GATEWAY_HOST_PORT`）。**`APP_JWT_SECRET`** 在 `user-service` 与 `gateway-service` 须一致。

## 未实现 / 未包含

| 项 | 说明 |
|------|------|
| Kubernetes | 未写 Deployment、Service、ConfigMap、探针接 K8s 等 |
| CI/CD | 未接 Jenkins、GitOps、自动构建发布流水线 |
| 可观测性深化 | 未接 Prometheus 全量指标、OpenTelemetry 等 |
| 网关 Swagger 聚合 | 未做；目前各服务直连端口各自 Swagger |
| Config 远端 Git | 当前为镜像内本地 Git；若课程要求远端仓库，需改 `spring.cloud.config.server.git.uri` 并自行管理凭据（勿把 token 写入仓库） |
| 仅网关对外 | Compose 仍将 9001–9003 等映射到宿主机，便于调试；若只要网关出口，需自行去掉对应 `ports` |
| MySQL 初始化脚本与 `.env` | 修改 `MYSQL_PASSWORD` 时须同步改 `docker/mysql/init/01-databases.sql` 中 `CREATE USER`，init 脚本不读 `.env` |

## Docker 全栈

在 `library-cloud` 目录：

```bash
docker compose up -d --build
```

- 主入口：`http://localhost:18888`（Nginx → Gateway）；等价调试：`http://localhost:18080`（网关）。
- 冷启动后若网关短暂 **503**，多为 Eureka 注册尚未完成，稍等再试。
